MEDIEVIL · LIVE MINIMAP

Build your maps once.

The minimap reads geometry and original textures from your own MediEvil USA disc (SCUS-94227). Your game and saves stay untouched.

1. Choose the game’s data track

Select Track 1.bin or a 2048-byte ISO image. For BIN/CUE games, choose the BIN containing the data track—not the CUE or audio track. CHD and other regions are not supported in v1.

Ready when you are.

2. Run your emulator

Windows / Linux: enable Export Shared Memory in DuckStation’s Debugging settings, then restart DuckStation. The minimap opens its RAM export read-only.

macOS: enable the local GDB server, normally port 2345, and use the Mac launcher. DuckStation may pause when the minimap connects; resume it manually.

Windows BizHawk (experimental, 2.11.1): keep one EmuHawk instance open, load your PS1 game, then open the read-only LiveMap Lua bridge in Tools → Lua Console. Run LiveMap in the same Windows session or VM. Native BizHawk gameplay verification is still pending.

PCSX-Redux: its standard shared RAM export is detected automatically. Keep only the emulator you want tracked open, or select one with the source command-line options.

Load your own game or save. Controller type does not matter for the minimap.

The image is transferred only to this computer’s 127.0.0.1 server. Temporary disc copies are deleted after extraction. Generated maps stay in your local app-data folder. No external upload or telemetry reporting.
